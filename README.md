# Blue Whale

Blue Whale — новый локальный Web-интерфейс и набор автоматизаций для конференц-зала **«Синий кит»**, построенный вокруг контроллера **Wiren Board**.

Проект создаётся с нуля. Старый интерфейс и старые скрипты используются только как reference по функциям, расположению и пользовательским идеям; старый код не является foundation новой реализации.

## Назначение

Система предназначена для управления и отображения состояния:

- фанкойлов;
- вентиляционной установки;
- режима проветривания;
- климатических показателей помещения;
- температурной уставки;
- RGBW-освещения через DMX;
- сцен освещения;
- источника управления DMX: `WB MQTT / ART-NET`.

Главный пользовательский интерфейс размещается на iPad в самом конференц-зале, поэтому Web проектируется touch-first и в первую очередь для landscape Safari/iPad.

## Верхнеуровневая архитектура

```text
                         iPad / Browser
                    HTML + CSS + JavaScript
                              |
                              | MQTT WebSocket /mqtt
                              v
                         Wiren Board
                              |
               +--------------+--------------+
               |                             |
            WB Rules                       DMXWB
               |                             |
     +---------+----------+             DMX512 / Art-Net
     |                    |                  |
  Fan coils           Ventilation        RGBW lights
  relay outputs          Modbus
```

Ключевой принцип: Web является пользовательским интерфейсом, а не главным движком автоматизации.

Автоматизация климатического оборудования выполняется в WB Rules. DMX/Art-Net подсистема освещения предоставляется отдельным существующим проектом DMXWB.

## Development model

Разработка разделена на уровни:

```text
Sprint
  -> Step
```

Основные спринты:

```text
DOC     — foundation и документация
WEB     — внешний вид и touch UX без реальной связи с контроллером
RULES   — WB Rules и виртуальные controls
JS      — реальная MQTT-интеграция Web
FINAL   — интеграция и acceptance
```

Текущую точку см. в `docs/PROJECT_STATE.md`.

Полный порядок см. в `docs/ROADMAP.md`.

## Development environment

```text

```

Основной репозиторий:

```text
https://github.com/Lex26p/bluewhale
```

Для Web-разработки достаточно Windows и обычного браузера.

WSL, CMake, Linux host build, Node.js/npm build и Docker не являются обязательной частью проекта.

## Offline requirement

Production Web должен полностью работать в локальной сети без Internet.

Если используются сторонние библиотеки, они должны храниться локально в проекте и не обращаться к CDN во время работы.

## Внешняя подсистема DMXWB

Репозиторий:

```text
https://github.com/Lex26p/DMXWB
```

Blue Whale использует публичный MQTT contract DMXWB для светильников, групп, сцен и выбора `WB MQTT / ART-NET`.

Blue Whale не является местом разработки физического DMX engine и не должен дублировать DMXWB.
